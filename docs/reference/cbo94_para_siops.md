# Prestigio ocupacional de Treiman a partir da CBO-94

Prestigio ocupacional de Treiman a partir da CBO-94

## Uso

``` r
cbo94_para_siops(cbo94)
```

## Argumentos

- cbo94:

  Vetor de codigos da CBO-94. Aceita "2-11.20" ou "21120".

## Valor

Vetor numerico com o escore de prestigio.

## Exemplos

``` r
cbo94_para_siops("2-11.20")
#> [1] 64
```
