# Prestigio ocupacional de Treiman (SIOPS) a partir do ISCO-88

Prestigio ocupacional de Treiman (SIOPS) a partir do ISCO-88

## Usage

``` r
isco88_para_siops(isco88)
```

## Arguments

- isco88:

  Vetor de codigos ISCO-88.

## Value

Vetor numerico com o escore de prestigio.

## Examples

``` r
isco88_para_siops(c("2221", "5220", "9130"))
#> [1] 78 32 21
```
