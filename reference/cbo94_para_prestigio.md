# Prestigio de Treiman a partir da CBO-94

Prestigio de Treiman a partir da CBO-94

## Usage

``` r
cbo94_para_prestigio(cbo94)
```

## Arguments

- cbo94:

  Vetor de codigos da CBO-94. Aceita "2-11.20" ou "21120".

## Value

Vetor numerico.

## Examples

``` r
cbo94_para_prestigio("2-11.20")
#> [1] 64
```
