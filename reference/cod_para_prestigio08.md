# Prestigio de Treiman ancorado na ISCO-08, a partir da COD

Prestigio de Treiman ancorado na ISCO-08, a partir da COD

## Usage

``` r
cod_para_prestigio08(cod)
```

## Arguments

- cod:

  Vetor de codigos da COD, de quatro digitos.

## Value

Vetor numerico.

## Examples

``` r
cod_para_prestigio08(c("2211", "9629"))
#> [1] 78.01 24.00
```
