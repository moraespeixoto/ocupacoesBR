# Indice socioeconomico ISEI a partir do ISCO-88

Indice socioeconomico ISEI a partir do ISCO-88

## Usage

``` r
isco88_para_isei(isco88)
```

## Arguments

- isco88:

  Vetor de codigos ISCO-88.

## Value

Vetor numerico com o escore ISEI-88.

## Examples

``` r
isco88_para_isei(c("2221", "5220", "9130"))
#> [1] 88 43 16
```
