# Indice socioeconomico ISEI a partir da CBO-94

Indice socioeconomico ISEI a partir da CBO-94

## Usage

``` r
cbo94_para_isei(cbo94)
```

## Arguments

- cbo94:

  Vetor de codigos da CBO-94. Aceita "2-11.20" ou "21120".

## Value

Vetor numerico com o escore ISEI-88.

## Examples

``` r
cbo94_para_isei("2-11.20")
#> [1] 77
```
